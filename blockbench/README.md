# Blockbench models

`tundra_direwolf.bbmodel` is the source of the Tundra DireWolf model.
It was converted to Minecraft's built-in model format in
`src/main/java/com/example/wolfhorse/client/TundraDireWolfModel.java` (no GeckoLib needed).
If the model changes, the Java model code needs regenerating from this file.
