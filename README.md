# Fangs of the Mountains

A Forge 1.20.1 mod that adds the DireWolf, a rideable mount with the brain of a wolf.

Download the latest jar from the [Releases page](../../releases/latest) and put it in your `.minecraft/mods` folder (needs Forge 1.20.1, 47.x).

## In game
- **Wild:** spawns in plains, meadows, forests, taiga and savanna. Hunts sheep and rabbits, attacks skeletons, fights back if hit. Can't be ridden.
- **Tame:** right-click with bones (1 in 3 chance per bone).
- **Sit / follow:** right-click your tamed one with a bone. Follows you and teleports if it falls 16+ blocks behind.
- **Fights for you:** attacks what hurts you and what you attack.
- **Ride:** sneak + right-click to add a saddle or armor, then right-click to ride. Owner only.
- **Heal / breed:** feed it meat. Two tamed ones make a tamed foal.
- **Spawn egg:** Creative menu > Spawn Eggs.
